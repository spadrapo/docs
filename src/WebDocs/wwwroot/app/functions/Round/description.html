The Round function rounds a numeric expression to a given number of decimal places, using the rounding direction you choose. It mirrors the rounding functions found in mainstream programming languages and adds explicit floor and ceiling directions.

The signature is Round(value, digits, mode):

  • value (required) — the numeric expression to round. Mustache and arithmetic expressions are resolved before rounding, so Round composes with Cast and any other expression.
  • digits (optional, default 0) — the number of decimal places to round to.
  • mode (optional, default round) — the rounding direction:
    • round — nearest value; exact halves are rounded away from zero (2.5 → 3, -2.5 → -3).
    • floor — toward negative infinity (2.9 → 2, -2.1 → -3).
    • ceiling — toward positive infinity (2.1 → 3, -2.9 → -2).

An unrecognized mode falls back to the default round behavior. Because Round returns a number, it can be displayed with d-model, stored with UpdateItemField, or nested inside other functions.
