The Cast can be used to resolve a expression into a specific type. By now we only support to cast to a number.

When casting to number, empty or non-numeric operands in an arithmetic expression are treated as 0. This means you can sum several fields where some may be blank — for example Cast({{jan}}+{{feb}}+{{mar}}+{{apr}},number) — and the unfilled fields simply count as zero instead of turning the whole result into NaN. No per-field default handling is required.
