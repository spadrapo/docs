You can use UpdateDataURL to update the GET URL endpoint associated with a data storage item — the endpoint used to load, and reload, the item's data.

This is the counterpart of UpdateDataUrlSet, which updates the SET (POST) endpoint used by functions such as PostDataItem. To re-fetch a storage item from a different endpoint at runtime, change its GET URL with UpdateDataURL and then call ReloadData. Changing only the SET URL does not affect ReloadData.

When the dynamic part of the URL is a value (for example a filter or an identifier), place it in the URL path and render the loaded data with an array storage item and d-for, so the displayed values refresh after every reload.
