Async executes a function or expression asynchronously, allowing the UI to remain responsive while the operation completes in the background. This is useful for non-blocking execution of time-consuming operations.

By default the content runs as an asynchronous continuation of the current task (a microtask). When a Timespan (in milliseconds) is provided, the content is instead scheduled with a timer and runs after the current task has fully completed; passing 0 defers it to the next task. This is useful when the work must observe state that only settles after the current event finishes - for example, deferring a Notify so a list re-renders after the browser has moved focus to the next field on Tab, which lets the focus be preserved.
