TicTacToe

A two-player (pass-and-play) TicTacToe built entirely with Drapo attributes and functions — no JavaScript. The board data key holds the nine squares (0 empty, 1 = X, 2 = O); the game data key tracks whose turn it is, the move count and the winner. Each square is a clickable button only while it is empty and the game is unfinished (d-if). After a move the handler checks all eight winning lines with IF, updates the running score, detects a draw when the board fills, and switches turns. New Game clears the board while keeping the score; Reset Score clears the tallies.
