Hangman

A very basic hangman game built entirely with Drapo attributes and functions — no JavaScript. The word is fetched from the backend (~/api/Hangman/GetWord) into the game data key; guess it one letter at a time — you lose after 6 wrong guesses. New Game calls ReloadData(game) to pull a fresh word from the server. A running score (kept in the score data key) tallies how many rounds you win and lose — it survives across games and is cleared by Reset Score.
