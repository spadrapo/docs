d-dragActive

You can use d-dragActive to turn the drag of a d-dragStart item on or off. It is a conditional, evaluated when the d-for item renders: when it is false the element gets draggable="false" and does not start a drag, so the mouse can select the text inside it (for example in an input that edits the item). Missing or empty means active.

The condition is evaluated again when the item re-renders, for example after a Notify of its data key. It applies to d-dragStart items rendered by d-for; the barber drag action ignores it.

Example

Syntax:

<div d-for="item in items" d-dragStart="row" d-dragEnd="row" d-dragActive="!{{item.editing}}">{{item.name}}</div>

Drag the rows to reorder them. The row being edited cannot be dragged, so its text can be selected with the mouse.
